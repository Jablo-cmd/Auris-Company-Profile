## Visual rules

- A4 portrait.
- 12-column grid.
- Nexus Navy #001A48 as structural colour.
- Auris Cyan #098FB4 for signal/accent.
- Signal Cyan #00B3BF for secondary emphasis.
- White space is intentional.
- Avoid card grids unless the information genuinely benefits from modular treatment.
- Use one dominant visual idea per spread.
- Use real product screenshots when available; never fabricate UI as evidence.
- Every case-study spread carries a visible evidence-status label.
- No unsupported metrics, logos, testimonials or certifications.

## Core diagrams

### Diagram A — Operating model
UNDERSTAND → DEFINE → DESIGN → BUILD → TEST → DEPLOY → IMPROVE

### Diagram B — Digital journey
WEBSITE → PORTAL → BUSINESS SYSTEM → AUTOMATION → DATA / BI → AI

This is a capability pathway, not a claim that every client requires every stage.

### Diagram C — Evidence model
DELIVERED | CURRENT CAPABILITY | AVAILABLE CAPABILITY | PLANNED

### Diagram D — Business value
CLARITY → CONTROL → EFFICIENCY → EXPERIENCE → GROWTH

Use this as a conceptual value chain, not a quantified outcome claim.
