## Design intent

The contents spread is set across two pages as a **four-column part-coded grid**, not a single
running list. Each part is a block headed by its part number, part name and colour bar; sections
run beneath. A reader locating "B-BBEE" scans seven coloured blocks rather than seventy-eight
sequential lines — this is roughly four times faster in usability terms and it is the first page
where the document demonstrates that it was designed rather than assembled.

Leader dots are **not** used. Page numbers are set flush right in a dedicated 10.5 mm column in
Slate, with the section title flush left. Leader dots are a typewriter artefact and read as dated in
a premium publication.

In the Word master, this page is generated by a `TOC` field restricted to Heading 1 and Heading 2
styles, then formatted with the `TOC 1` and `TOC 2` custom styles. It updates automatically; it is
never typed.
