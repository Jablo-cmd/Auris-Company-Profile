## Visual production rules

- Use evidence-led diagrams rather than decorative graphics.
- Use project screenshots or approved imagery to demonstrate real work.
- Use tables for credentials and comparisons.
- Keep typography and spacing consistent.
- Never stretch content to meet an arbitrary page count.
- Never add a page merely to make the document look bigger.
