# 4.0 Engineering Capability

Auris Nexus uses technology as a means to deliver a business outcome.

Our engineering capability is strongest in modern web and business-application development, structured data systems, automation, integrations and practical AI-enabled functionality.

## Current technology examples

| Area | Current examples |
|---|---|
| Front end | React 18, TypeScript, Vite, Tailwind CSS |
| Data | PostgreSQL, Supabase |
| Server-side / functions | Supabase Edge Functions, Deno |
| Source control | Git, GitHub |
| Deployment | Solution-dependent; GitHub Pages where appropriate |
| Application capability | Authentication, RBAC, multi-tenancy, dashboards, workflows, APIs |
| Engineering controls | Testing, row-level data controls, version-controlled development |

This is an example of the technology used across current Auris-built systems, not a promise that every engagement will use the same stack.

## How we engineer

### Architecture
We structure applications around clear business domains, roles, data relationships and maintainability.

### Data
We design data models around the records the organisation needs to manage and the decisions it needs to make.

### Access
Where sensitive or multi-tenant information is involved, permissions and data-layer controls are considered as part of the architecture.

### Integration
APIs and structured data exchange can connect systems that would otherwise require duplicate capture or manual reconciliation.

### Automation
Repetitive work can be converted into controlled workflows, notifications, approvals and system actions.

### AI
AI is applied where a specific task, information set or decision-support opportunity justifies it.

### Quality
Testing, review and controlled release are part of development rather than an afterthought.

## Technology should remain understandable

Auris Nexus does not believe that a solution becomes better because its architecture is more complicated.

The standard is:

**appropriate technology + sound engineering + clear business purpose.**
