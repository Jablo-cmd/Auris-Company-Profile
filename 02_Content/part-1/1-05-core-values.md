# 1.5 Core values

**Standfirst**

> Six values the founder has set the company against, stated plainly rather than dressed up — each
> one a description of how we intend to work, not a slogan for the wall.

---

## Copy

### Introduction (spread opener)

Most corporate values are unfalsifiable. "Integrity", "excellence" and "innovation" appear on the
walls of every company that has ever failed a client, because no behaviour could contradict them.
These six are stated as commitments about how work actually gets done here — practical to state
plainly precisely because the company is small enough that each one is a personal commitment of the
founder, not a policy applied to a workforce.

---

### The six values

Set as component C09 feature cards, 2 × 3 across the spread.

---

**1. Practicality**
`fa-crosshairs`

We focus on solutions that address real problems and create meaningful operational value.

---

**2. Integrity**
`fa-user-check`

We communicate honestly about our capabilities, experience, delivery status, and commitments.

---

**3. Innovation**
`fa-comment-check`

We explore appropriate technologies and better ways of solving business problems.

---

**4. Quality**
`fa-arrows-to-circle`

We aim for reliable, maintainable and user-focused solutions rather than technology for its own sake.

---

**5. Partnership**
`fa-people-arrows`

We work collaboratively with clients and stakeholders to understand their needs and build solutions
around them.

---

**6. Continuous Learning**
`fa-scissors`

We continually improve our technical capabilities, processes and understanding of the environments in
which our clients operate.

---

## Production notes

- **Card grid:** 2 × 3 across pp. 14–15, component C09. Card heights equalised across each row.
  `space-5` (15 mm) gutters. Top-left corner cut at 3 : 5 on every card.
- **Resolved 2026-09-13, Stage 9.** These six values and their descriptions are owner-authorized
  wording, supplied directly by the founder — see Fact Register **B4**. The previously drafted
  proposal (Precision, Accountability, Candour, Continuity, Proximity, Restraint, each with a
  separately invented "operational test" line) is superseded entirely. **The operational-test
  structure is dropped, not carried forward** — it was written for a different value set and inventing
  a new test per value here, unprompted by the owner, would itself be exactly the kind of unevidenced
  embellishment this project's method exists to avoid. If the owner later wants an evidence-backed test
  per value, that is a future addition, not something to improvise now.
- Icon assignments above are carried over from the prior draft's grid positions for layout continuity
  only — they do not carry semantic meaning tied to the old value names. Reassign at Stage 10 layout
  review if a better thematic fit exists per value (e.g. a growth/learning icon for Continuous
  Learning rather than the inherited scissors mark).
- Six values is the ceiling. Beyond six, none is remembered; the spread also only holds six cards at
  legible size — this matches the owner-supplied count exactly.
- **Cross-reference note:** `02_Content/part-5/5-07-continuous-improvement.md`'s production notes
  previously referenced "1.5 (Restraint)" by the old value name; that value no longer exists under
  that name and the cross-reference has been updated to point to **Continuous Learning** instead,
  which is the closer thematic match.
